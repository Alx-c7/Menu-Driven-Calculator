# Menu Driven Calculator

## What is this 
This is a Calculator that has a menu system for the user to navigate through the program.
It is able to calculate addition, subtraction, multiplication, division, power, and modulus.

## Instructions
1. Input a integer 0-6 to access the calculation you wish to access
     (the navigation to what will be shown in the programs menu)
2. Input the first number
3. Input the second number
4. Repeat as desired

## Sample Input
1
5
6

## Sample Output 
Addition
First Number: 5
Second Number: 6
11
